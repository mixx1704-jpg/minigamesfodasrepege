# Minigames Fome e Justiça

Site estático, responsivo e sem dependências. Funciona direto no GitHub Pages.

## Publicar no GitHub Pages

1. Envie `index.html`, `styles.css`, `app.js` e `.nojekyll` para a raiz da branch `minigame`.
2. No repositório, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `minigame`, pasta `/ (root)` e clique em **Save**.

Os caminhos dos arquivos são relativos, então o site funciona mesmo quando o repositório é publicado em uma subpasta do GitHub Pages.

## Testar no computador

Abra `index.html` no navegador. Não é necessário instalar nada ou executar comandos.
